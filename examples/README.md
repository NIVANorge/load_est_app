# Example datasets

This folder contains example datasets illustrating how to use the template and for testing the app.

 * `ex1_drammenselva_totp.xlsx`. TOTP data from Drammenselva. A fairly small dataset suitable for initial testing.
 * `ex2_glomma-drammenselva_totn-totp.xlsx`. TOTN and TOTP data from Drammenselva and Glomma. A medium dataset illustrating how to provide data for several sites and parameters.
 * `ex3_oslofjord_rivers.xlsx`. A larger dataset containing multi-parameter nutrient data for several Oslofjord rivers (Glomma, Alna, Drammenselva, Numedalslågen and Skienselva).
 * `ex4_langtjern.xlsx`. Long and detailed time series from a single station in an intensively monitored research catchment.
